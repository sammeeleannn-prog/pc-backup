# PC Backup - Privacy Policy

Last updated: 19 November 2026

PC Backup is a personal backup tool. It is used only by its owner, on the owner's own computer, to copy the owner's own files to the owner's own Google Drive using rclone.

## What data the app accesses

The app uses the Google Drive API to create, update, list and delete backup files in a folder named PC-Backup in the owner's Google Drive. It does not read any other Google account data.

## How data is used and stored

Files go directly from the owner's computer to the owner's Google Drive. No data is sent to, stored on, or shared with any other server or third party. The app has no server of its own and does no analytics, tracking or advertising.

## Use of Google user data

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Removing access

The owner can remove the app's access at any time at https://myaccount.google.com/permissions
